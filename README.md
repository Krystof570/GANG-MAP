# CREW MAP

Soukromá sdílená mapa vzpomínek pro přátele.

## Plánovaný stack

- Next.js + React + TypeScript
- Tailwind CSS
- Supabase Auth, Database a Storage
- Leaflet + OpenStreetMap

## Stav projektu

Repozitář byl při zahájení vývoje prázdný. Aplikace bude budována postupně s důrazem na mobilní použitelnost, izolaci dat jednotlivých skupin a serverově vynucená oprávnění.

## Vývoj

1. Základ aplikace a designový systém
2. Autentizace a profily
3. Skupiny a bezpečné pozvánky
4. Fotografie, galerie a mapa
5. Zabezpečení pomocí Supabase RLS a Storage policies
6. Testování a nasazení
